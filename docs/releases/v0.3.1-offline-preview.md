# Polymath Offline 0.3.1 — model-included Android preview

This APK includes Qwen3-0.6B Q4_K_M and runs source-based AI chat on the Android device. No HTTPS inference endpoint or API key is required.

Install **Polymath_0.3.1_offline_preview.apk** and open **Polymath Offline**. It installs separately from the older Polymath app and does not move or delete its data.

1. Open Desk → chat icon → Set up offline AI.
2. Tap Prepare included AI and wait until ready. No extra model download is needed.
3. Add the example dataset under Datasets, select Polymath foundations, and ask: What voltage is needed for 2 amps through 6 ohms?
4. Check the answer against its source citation. This flow works in airplane mode.

The chat version label must read **Polymath 0.3.1 · Offline preview**. HTTPS and key fields are only available behind the optional private-server action.

The APK is 657,299,390 bytes (about 657 MB), including a 397 MB model. Allow about 3 GB free storage for downloading, installation and model preparation. Android 9+, a supported 64-bit device, roughly 4 GB RAM or more and enough available memory are needed.

The exact APK passes the bundled-model identity/checksum checks and a real Android UI test from first setup to a cited answer in airplane mode. Build/test details are in BUILD_INFO.json; SHA256SUMS identifies the APK bytes. This is a debug preview: physical-phone performance, broad answer accuracy and production signing remain open. The model answers from selected sources; it does not browse the live web.
