# Polymath 0.2.0 — Initial Android test build

Download **Polymath_0.2.0_debug.apk** from the assets below. This is an early development build for community testing on **Android 9 or newer**, not a production store release. No GitHub account is required to download it.

## Install and try

1. Download the APK on your Android device and open it.
2. If Android asks, allow installation from the browser or file manager used for this download, then install Polymath. You can turn that permission off afterward.
3. Choose your topics, swipe through knowledge pills, save a card, write a note, and explore the Vault and learning graph. No account or AI service is needed for these features.
4. For AI chat, follow the [self-hosted service setup](https://github.com/Bhargav2301/polymath_ai_news_chat/tree/main/services/rag#readme), then configure **Desk → chat icon → Connection**. The APK includes no hosted AI endpoint or API key.
5. Report problems through [GitHub Issues](https://github.com/Bhargav2301/polymath_ai_news_chat/issues), including your device, Android version, steps to reproduce, and screenshots without private information.

## Build and installation notes

- App version: **0.2.0**, version code **2**, package **com.polymath.app**.
- This APK comes unchanged from the [successful Android verification run](https://github.com/Bhargav2301/polymath_ai_news_chat/actions/runs/34100208781) for source commit `9ad4081e9657e2449eb92378b47444612f32fc5b`. The release tag adds publishing documentation and workflow configuration; application source is unchanged.
- `SHA256SUMS` and `BUILD_INFO.json` identify the exact downloadable APK and its build provenance.
- This APK uses the CI-generated debug signing key. An earlier locally shared APK may have a different signature and reject an in-place update. Uninstalling it deletes local notes and saved data; preserve anything important before choosing a fresh installation. Export/restore is not implemented yet.
- Reading, notes, recommendations, keyword search and EXP work locally. News and source images need internet access; AI chat requires your configured service. Physical-device performance and production deployment remain unverified.

The workflow publishes this fixed build once and does not replace existing release assets. Future builds should use a new versioned release.
